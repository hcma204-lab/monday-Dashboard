monday 連線

在 claude.ai 開啟本頁時，會自動使用 claude.ai 的 monday 連線，不用設定。用其他方式開啟（例如 GitHub Pages）時，請貼上你自己的 monday 個人 API token：monday 左下角頭像 → Developers → My access tokens（選單名稱可能依 monday 版本略有不同）。

token 只存在這台電腦的瀏覽器，不會上傳到任何伺服器，也不會進入程式碼；資料只在你的瀏覽器和 monday 之間傳送。你能看到哪些看板，取決於你自己的 monday 權限。token 等同你的登入權限，請勿貼到不信任的頁面，也不要貼到公用電腦。

    🤖 系統自動帶入，等你處理 🕹️ 由你手動切換 ⛔ 尚未開始 請勿提前切換 ❌ 不需執行 不要點 剩餘天數 = 預計完成日 − 今天 點單號：開啟 monday 項目，關閉右側面板後該列會標亮
